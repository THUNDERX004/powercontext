# MiniMax evidence

`sddctx dev` creates one timestamped directory here containing:

- the exact selected context;
- the redacted MiniMax request;
- the raw MiniMax response;
- a pre-change source snapshot;
- applied-file hashes and token usage;
- a development log and unified diff.

The final validation run directory is referenced by
`records/powercontext-log.md` and `records/resume-context.md`.
