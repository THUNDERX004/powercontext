# Recorded Results

All files were generated by this submission on 2026-11-04. No timing or quality
value was copied from an external benchmark.

## `quality/`

- `summary-auto.json`: FP32 vs FP16 with WebGPU; three fresh-page runs per precision.
- `summary-wasm.json`: FP16 WASM aggregate; three fresh-page runs.
- `quality-*-auto.json`: raw aggregate plus all three per-run samples for WebGPU.
- `quality-fp16-wasm.json`: raw aggregate plus all three per-run samples for WASM.
- PNG files are screenshots of the browser quality page after completion.

The model files were served from the pinned Hugging Face revision. Only the
model's dense ranking quality was evaluated here; main application storage and
retrieval are covered by `evidence/`.

## `evidence/`

- `browser-smoke-webgpu.json/png`: complete WebGPU run with 8 imports, five
  query samples, refresh visibility checks, temporary empty-collection test,
  switch-back test, and raw per-import timings.
- `browser-smoke-wasm.json/png`: same workflow after `navigator.gpu` is made
  unavailable in the isolated browser context. The app reports WASM in the UI.

Raw JSON is the source of truth for medians and exact timing boundaries. PNG
screenshots are visual evidence of the final rendered state.
